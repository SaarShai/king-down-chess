**1) Verdict**

The Workshop has a strong visual style and a useful core flow.  
It is not ready to release: saving, sharing, and Try it have major faults.  
Phone editing hides important controls and makes scrolling risky.  
The judge explains too much with numbers that look more certain than they are.  
Keep the art direction. Fix behavior and accessibility before adding motion.

Verification: **28 Workshop tests passed** with a review-only configuration. Focused [code probes] (not kept in the repo) confirmed several additional faults. The sandbox blocked the dev server on port 5199, so I could not run browser checks. No tracked files changed.

**3) The five changes with the greatest benefit**

1. **Make saving and sharing dependable.** Remove false success messages, prevent silent shelf eviction, and make every allowed design shareable.
2. **Make Try it show the real rules.** Fix action choices, rook chains, immunity messages, and keyboard focus. Test custom combinations, not only presets.
3. **Make the next painting action clear.** Always show the active brush and Paint on mode. Fix pointer release. Keep the full landscape grid visible.
4. **Rewrite the judge’s explanation around comparisons.** Show what changes when a feature is removed. Separate assumptions from measurements. Preserve ordinary-piece exceptions.
5. **Make dialogs safe to operate by keyboard.** Keep shortcuts inside the active sheet, allow deliberate choice confirmation, and restore focus after changes.

**4) Keep these strengths**

- **The painted parchment style works.** The figures, dark stage, Cinzel headings, burgundy buttons, and stone borders fit the main game.
- **Moves, Rules, and Look form a clear structure.** The three-rule limit and sentence-based controls help contain complexity.
- **The main controls have generous targets.** Selected bodies and glows use both a border and a tick.
- **The editor grid has useful keyboard foundations.** Its square labels and roving focus are worth reusing in Try it.
- **Warnings allow experimentation.** Players can keep a strong piece, inspect Why?, and undo a suggested change.
- **The revised chain flow is clearer.** Showing the next capture immediately, with Finish available, is better than an extra confirmation step.
- **The code separates calculation from presentation.** Pure model, judge, and movement modules support focused tests. Recomputing the verdict when a link opens is also sound.
- **Motion remains outside the shipped editor.** Keep that boundary until the preview behavior is corrected and approved.
