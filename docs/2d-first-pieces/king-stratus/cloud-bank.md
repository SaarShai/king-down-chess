# Cloud ground sprite

`cloud-bank.png` is a transparent ground-effect sprite made with the built-in image generation tool. It does not replace or alter the original Sky King painting.

Prompt: One full fluffy cloud bank on a transparent background. Wide horizontal composition. A low hovering cushion of dense billowing cumulus, seen from a slightly elevated three-quarter frontal camera, below a painted fantasy chess king. Dense filled center; no hole, rings, swirls, spiral, ground, pedestal, character, landscape or text. Seven to ten irregular fused puffs. Painterly fantasy board-game illustration, textured gouache, warm ivory upper highlights, pale blue-gray occlusion in folds and underbelly. Rounded volumetric forms, feathered wisps, opaque middle. No vector outlines or smooth plastic spheres.

Reference direction: Airborn Studios' art-directed cloud volumes, described by its artists at https://80.lv/articles/airborn-3d-production-of-a-stylized-ue5-animation . The reference informed the volume and grouping; no source artwork was copied.
