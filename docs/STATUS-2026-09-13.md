## The game
- Chess960-style random back rank from the pool Q L R R B B N N A A G G M M S S + K, mirrored, bishops on opposite colours; no castling, no en passant; promotion to any non-king piece.
- Five fairy pieces with the rules measured this session (v0.6): archer and beast step one square in any direction; the guard may capture one pawn in its lifetime and step up to two squares; paladin and maester as in the 2017 rulebook. The 2017 and 2021 rule sets remain selectable.
- Look: "Dungeon" (your pick B2) — painted 3D voxel sculpts from your STLs, stone tiles from your Drive, torch lighting, 53° camera, orbit/zoom/pan, coordinates; 13 other presets still switchable.
- Loop: human or computer per side, undo, resign, game-over dialog with rematch, autosave and restore, captured pieces, piece info card, copy move list, keyboard shortcuts, mobile layout.
- AI: alpha-beta with transposition table, quiescence and a Texel-tuned evaluation (+113 Elo over the hand-tuned one); depth 6–7 in one second in the browser.
- Quality: 102 automated tests (rules perft, every fairy mechanic, AI puzzles, self-play legality, game loop, simulation lab), 8 full games played through the real UI, 5 game-loop bugs found and fixed.

## The balance lab (`npm run sim`, `npm run sim:analyze`, `npm run dashboard`)

### Findings that beat noise
| Question | Answer |
|---|---|
| First-move advantage | White +25–30 Elo (score 0.52), stable from depth 3 to 5, unchanged by the new rules |
| Piece values (tuned engine, pawns; knight 3.0) | archer 3.4, beast 2.7, paladin 2.2, maester 2.2, guard < 1.5 |
| What makes games long and drawn | guards (+20 draw points for two, at equal army value); more fairy pieces at equal value; the queen is the biggest sharpener |
| The paladin | the only piece that shifts balance (+20 White points per paladin); two paladins beat two maesters by 61 Elo at equal table value |
| Placement | almost nothing: maester beside the king +15 Elo for White; archers adjacent +3 draw points; king position irrelevant |
| Beast chains | flavour: removing them only lengthens games |
| Rule toggles | only "guard capturable by anyone" changes the game (+5 decisive); archer checks, maester long swap, promotion set, bishop colours measure nothing |
| Your 2021 archer/beast | archer 84 Elo weaker than 2017; beast equal but twice as active |
| Engine strength | each search ply ≈ +180 Elo; balance conclusions are depth-stable, interest rankings are not (they survive a ply, ρ 0.81, but not rule changes) |

### Rule decisions taken (docs/RULES.md §6)
1. Archer steps any direction (1.7 → 3.4 pawns). 2. Beast steps any direction (1.7 → 2.7). 3. Guard: one pawn capture per lifetime + 2-step (the uncapped version harvested pawns in 44 % of games). 4. Beast chains, archer checks, maester long swap kept. 5. AI values tuned from data, not by hand.
