## Standards

The independent standards review found four actionable correctness/evidence issues:

1. **Replay does not enforce legality.** `src/sim/replay.ts:51–60` parses and round-trips LAN before unchecked `makeMove`; `src/sim/tune.ts:259–291` is a syntactic parser. The reviewer reproduced acceptance of illegal `e2-e5`. The plan requires legal replay, and the function's comment explicitly claims it. Fix the legality boundary before treating this as an audit guarantee. This is not evidence that every existing game or the Q6 model is invalid.
2. **Condition statistics omit Black and misstate owner rates.** `tools/conditions.ts:39–42` leaves Black's FEN rank lowercase, whereas recorded statistics use uppercase piece keys. Its displayed uppercase rows therefore contain only White's counts, yet line 101 divides by twice the number of games. It also does not count actual owning armies when a piece is absent from some starts. Recompute affected activity/paralysis claims before using them to decide rules.
3. **The older liveliness fit is mixed-depth despite its label.** `tools/liveliness.ts:30–32` assigns all aggregate rows to `depth3`. Input `_meta.runs` includes 1,600 depth-4 games; the report calls all six inputs depth 3. The arrangement-level holdout is useful, but that population description is wrong. No filter was adopted, limiting practical impact.
4. **Source identity misses a dependency.** `src/sim/identity.ts:18` hashes rules, AI and simulation directories, but `src/sim/game.ts:6` also imports `src/game.ts`. A change there can alter a run without changing this source identity.

The finalist split calculation itself is valid: `sim/specs/arrangement-2026-09-17/analyze.ts:319–328` alternates within each arrangement's sorted records. The report's phrase “gameId parity” is inaccurate, not a reason to discard those halves. The interaction profiler also omits Strike events; this is a secondary coverage limitation for a shelved feature.

## Corrections to the final game-design synthesis

- **Paladin is a priority hypothesis, not a settled removal decision.** I reproduced the pool comparison: White +6.225 percentage points at depth 3, 95% interval +3.381 to +9.069; at depth 4, +3.813 points, interval **−0.345 to +7.970**. The deeper paladin-containing subgroup is positive, but the overall interval crosses zero. There are zero matching back ranks between the two pool arms. Shared random-number seeds do not make these identical positions with only a Paladin changed. See `sim-paladin-pool-2026-09-17.md`.
- **The Archer's quoted deeper confirmation is for another shot pattern.** The +8.8 ±3.8 decisive-point result tests `plusDiag2` (all four longer diagonals). The adopted `plusDiagFwd2` adds only the forward pair; its direct documented result is depth 3 (+8.2 ±2.7). Do not transfer the deeper number between rules. See `sim-piece-balance-2026-09-17.md:30–68` and `src/rules/rules.ts:374`.
- **Arrangement order has not been isolated.** `src/sim/experiments.ts:220–231` eliminates configurations primarily by estimated balance, not the pre-registered residual-interest score. The two sweeps shared no configurations. Their candidates have different piece mixtures as well as different order. Composition is a promising lever; “order is mostly noise” is not established by a controlled same-composition permutation experiment. Within the selected 50, the extreme scores are useful shortlist evidence. At deeper search only `KGBMSSMB` passes the study's own point cutoff; this also does not prove its true score is within three points of 50%.
- **The kit-rich gain is conditional on the sampled setups.** The saved +0.265 mechanics/game is correct. The quoted narrow interval treats 2,000 games as the inferential unit although each arm contains only 40 sampled arrangements. A simple sensitivity calculation using the 40 arrangement means per arm gives an approximate interval **−0.029 to +0.559** (`difference ±1.96*sqrt(var(A)/40+var(B)/40)`). This is not a definitive replacement for a full clustered analysis; it shows that generalization to new arrangements needs testing. The metric also counts any Beast capture as that mechanic, not only multi-capture chains. More counted mechanics is not measured human creativity.
- **Push mostly helps friendly repositioning.** At O=318 I counted **5,185 shoves: 5,145 friendly, 40 enemy**, over 1,600 games. Thus 99.23% were friendly. The deeper decisive-share gain is about seven points, but the run does not demonstrate frequent enemy displacement or a solution to Guard blockades. Changing the evaluation price changes how this AI plays; it does not change the human rules or prove human fairness. The control's missing game also exposes an unresolved search slowdown. See `sim-ogre-combos-2026-09-17.md`.
- **Adjudication and player strength matter.** The older full-game comparison is 79.1% decisive with adjudication versus 87.2% without; its arms do not share opening streams, so treat the exact difference as a diagnostic, not a paired causal estimate. Most later work still uses shallow linear self-play and adjudication. Draws, engine-declared draws and games hitting the length cap need separate columns. No amount of game count removes shared evaluator blind spots.
- **Guard starting on the pawn row remains untested in the current one-Guard game.** The old front/split specs never ran and assumed two Guards. Current random setup puts a drawn Guard on the back rank. Midgame visits to the pawn row do not answer the starting-placement question. See the `gs-wall-front` and `gs-wall-split` item under the heading “Dropped” in `docs/QUEUE.md`, and `src/rules/setup.ts:30–42`.

## Five next steps, in priority order

These are proposals, not a launched queue. Sample sizes are bounded starting budgets, not promises of statistical power. Specify the smallest worthwhile effect before running; an inconclusive result stays inconclusive.

1. **Confirm the exact current game with stronger players and complete endings.** First repair the replay, source-identity and condition-statistics checks; preserve historical data. Freeze current rules, values and source. Use at least 80 explicit setups spanning the important piece mixes. Start with 400 games per condition, expanding the key confirmation to roughly 1,600 per condition. Compare the current linear and residual evaluators at a practical equal budget, with a deeper linear check; disable early win/draw adjudication for the confirmation. Directly test the adopted forward-only Archer against classic shots with today's all-direction Beast and standard promotions held fixed. Review long Beast chains, blocked Guards and actual endgames. The decision is whether present conclusions survive better play, not whether to invent another ability. Lab Ogre positions fall back to linear, so a residual-labelled Ogre match would not be an independent check.
2. **Isolate the Paladin's first-move advantage before weakening or removing it.** On about 80 matched setups keep six non-king pieces and their locations fixed, comparing a Paladin in the remaining slot with specified replacement pieces in separate arms. Sample its starting file and king distance deliberately. Use fresh seeds and roughly 2,000 games per arm at the confirmation setting, with full endings and arrangement-clustered uncertainty. Review 20–30 strongest White opening lines with deeper defence and human players. Replacing a piece is still a substitution effect; agreement across replacements would make the Paladin explanation stronger. Change a rule only after identifying a repeatable mechanism and credible counterplay failure.
3. **Test the Ogre against the experience we want: relocating opponents.** Keep push and repel as the leading readings. Use 12–20 deliberately constructed positions covering enemy contact, pawn fronts, Guard walls, pins, board edges and Ogre–Beast/Archer combinations; play both sides, then embed the useful cases in full games. Compare with-capture and no-capture only where this changes the enemy-displacement decision; the existing generic no-capture result does not settle that interaction under push. Measure enemy shoves, useful friendly shoves, immobilization and available replies separately. A subsequent 1,600-game full-game confirmation should precede a roster choice. Preserve enemy targeting; do not adopt friends-only just because it improves an automated win/draw number. Keep hop/step-two additions shelved unless these targeted sessions expose a clear need.
4. **Run the missing one-Guard pawn-row experiment.** Build matched starts by swapping the Guard with the pawn directly in front of it, for both armies, preserving all pieces; compare with the identical normal back-rank start. Label this explicitly as a Guard–pawn setup swap. Include central/edge files, near/far king positions and Archer/Beast-heavy opponents. Start with 400 games per arm, then confirm a meaningful effect at roughly 1,600 and a stronger setting. Track development time, pieces trapped behind the Guard, prolonged blockades, promotion access and fairness; include a dozen human position sessions. If the game does not feel or measure better, retain the existing setup rule.
5. **Validate creativity with controlled arrangements and people.** First hold composition fixed: choose eight representative mixtures and six legal permutations of each, including the current shortlist as examples. About 100 games per permutation is a screening budget (4,800 total); retest extremes on unseen opening seeds without overinterpreting neighbouring ranks. Separately compare the current draw pool with a modest fairy-rich candidate that preserves the possibility of two bishops; report lost mixture diversity. Run 24–36 full human games with 8–12 players across experience levels, rotating conditions and swapping colours. Ask about meaningful plans, surprising but understandable interactions, helplessness, rule-recall errors and desire for a rematch. Include tactical Beast/Archer/Ogre examples. Human feedback is qualitative at this size; use it to validate the proxy and choose the next precise experiment, not to claim population-wide preference.

Keep the simple adopted Beast, standard promotions and ordinary draw rules as the working baseline. Leave the other paused lab pieces and king-power expansions paused. When results are near equal, the default decision remains the simpler existing rule.
