# Connect studies to the balance evidence

Status: needs-info
Type: task
Blocked by: 03 and owner approval of the framework spec

## Outcome

A designer can prepare a controlled study, inspect its context and cost, and
read a result linked to the exact design. The system cannot turn missing data
into a pass or launch a campaign merely because a plan is complete.

## Scope

Review and integrate the later balance campaign, combination, action-trace and
identity work listed in [the source review](../source-review.md). Reconcile each
part with current main. Preserve historical report contexts and raw sources.

Repair complete policy identity before using a run for policy comparisons.
Include `powerHold`, `powerHoldSides` and every setting that `playGame` reads in
the experiment context and resume guard. Register worth, activity, field,
four-cell interaction and cross-play recipes through existing sim jobs.

Attach estimates, intervals, independent block counts, validity, coverage and
approval to evidence records. Keep design worth estimates apart from measured
worth. Report ordinary, special and passive-effect activity separately.

## Checks

- Any relevant rule, value, policy or source change invalidates resume identity.
- Same context and schedule reproduce the same deterministic fixture results.
- Missing four-cell rows, duplicate IDs, mismatched starts and altered hashes fail validation.
- Known-zero and known-nonzero synthetic contrasts check the analysis path without games.
- Block dependence, family intervals, unresolved caps and stale evidence have tests.
- Reports distinguish effect interaction, policy contrast and whole-pool outcomes.
- Current approved criteria stay fixed; proposed bands stay labeled as proposed.
- `npm test` and `npm run balance:check` pass. Preview controls do not launch jobs.

## Runs

A later named campaign records its owner quote in main's queue before launch.
Use the mounted-card resolver, existing M1/Kaggle rules, frozen source, validation
and verified backup. A test smoke stays within the standing limits. This ticket
does not authorize a campaign or a rule change.
