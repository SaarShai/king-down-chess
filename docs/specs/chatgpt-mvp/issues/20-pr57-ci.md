## Join root cause (ported from claude/od-fixjoin)

- The Join remount wait above hides a product fault. The static code field takes text before the mount ends. At the end of the mount, `joinScreen()` writes the code from the new page's memory, which is empty, and clears what the player typed. Join then stays hidden.
- `claude/od-fixjoin` finds this cause (`1be2573f`, `ee297c75`). The port takes only the fix: `actions()` blocks `#join-code` with the screen buttons, so the field takes text only after the Join handlers are ready.
- The new app test `reads a friend code again after the join preview remounts` holds the mount read, types the code, then releases the read. It fails on the old code (`#join-confirm` stays hidden, 7.1 s) and passes with the fix.
- The browser check types again as soon as the code field shows, with no wait for the mount. Playwright's fill waits for the enabled field, so the check finds the fault if it comes back.
