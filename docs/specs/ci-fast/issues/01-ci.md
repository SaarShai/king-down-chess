# Run one full CI check per tested tree

Status: claimed

Use shards for test files and browser checks. Record the tree when the required checks pass.
Use the record to skip work on the same tree and to guard a document-only run.
Check the changed paths before the merge tool accepts a lead review of a screen tweak.

## Check the document path

The base tree needs a green record before CI can skip the browser jobs.
A manual run with a base SHA can check this path. A manual run without a base SHA runs the full suite.
Record the run links in the handoff. The lead checks reuse after a real PR merge.
